/**
 * @template TValue
 * @implements IteratorAggregate<array-key, TValue>
 */
final class DemoContainer implements IteratorAggregate, Countable, ArrayAccess
{
    /** @var array<array-key, TValue> */
    protected array $data = [];

    /** @param array<array-key, TValue> $data */
    public function __construct(array $data = [])
    {
        $this->fill($data);
    }

    /** @param array<array-key, TValue> $data */
    public static function make(array $data = []): static
    {
        return new static($data);
    }

    /** @return TValue */
    public function __get(string $name): mixed
    {
        if (!array_key_exists($name, $this->data)) {
            throw new InvalidArgumentException("The {$name} key does not exist in the container.");
        }

        return $this->data[$name];
    }

    /** @param TValue $value */
    public function __set(string $name, mixed $value): void
    {
        $this->data[$name] = $value;
    }

    public function __isset(string $name): bool
    {
        return isset($this->data[$name]);
    }

    public function __unset(string $name): void
    {
        unset($this->data[$name]);
    }

    public function __toString(): string
    {
        return json_encode($this->data) ?: '{}';
    }

    /** @return TValue */
    public function get(mixed $name): mixed
    {
        if (!array_key_exists($name, $this->data)) {
            throw new InvalidArgumentException("The {$name} key does not exist in the container.");
        }

        return $this->data[$name];
    }

    /** @param TValue $value */
    public function set(mixed $name, mixed $value): static
    {
        $this->data[$name] = $value;

        return $this;
    }

    /** @param array<array-key, TValue> $data */
    public function fill(array $data): static
    {
        $this->data = $data;

        return $this;
    }

    /** @param array<array-key, TValue> $data */
    public function merge(array $data): static
    {
        $this->data = array_merge($this->data, $data);

        return $this;
    }

    /** @param TValue $value */
    public function push(mixed $value): static
    {
        $this->data[] = $value;

        return $this;
    }

    /** @param array<int, array-key> $keys */
    public function contains(array $keys): bool
    {
        foreach ($keys as $key) {
            if (!array_key_exists($key, $this->data)) {
                return false;
            }
        }

        return true;
    }

    /**
     * @param array<int, array-key> $keys
     *
     * @return array-key|false
     */
    public function missing(array $keys): mixed
    {
        foreach ($keys as $key) {
            if (!array_key_exists($key, $this->data)) {
                return $key;
            }
        }

        return false;
    }

    /** @return array<array-key, TValue> */
    public function toArray(): array
    {
        return $this->data;
    }

    /** @return array<array-key, TValue> */
    public function all(): array
    {
        return $this->toArray();
    }

    /** @return ArrayIterator<array-key, TValue> */
    public function getIterator(): ArrayIterator
    {
        return new ArrayIterator($this->data);
    }

    public function count(): int
    {
        return count($this->data);
    }

    public function offsetSet(mixed $offset, mixed $value): void
    {
        if ($offset === null) {
            $this->data[] = $value;
        } else {
            $this->data[$offset] = $value;
        }
    }

    public function offsetExists(mixed $offset): bool
    {
        return isset($this->data[$offset]);
    }

    public function offsetUnset(mixed $offset): void
    {
        unset($this->data[$offset]);
    }

    /** @return TValue */
    public function offsetGet(mixed $offset): mixed
    {
        if (!array_key_exists($offset, $this->data)) {
            throw new InvalidArgumentException("The {$offset} key does not exist in the container.");
        }

        return $this->data[$offset];
    }
}

function show(string $label, mixed $value): void
{
    echo str_pad($label, 28) . json_encode($value) . PHP_EOL;
}

What it is

DataContainer is a final single-generic (@template TValue) wrapper around array<array-key, TValue>. The class itself is 29 lines — use IsDataContainer + static::make() — with all behavior in the IsDataContainer trait and the contract in DataContainerInterface (IteratorAggregate + Countable + ArrayAccess, get/set/fill/merge/push/contains/missing/toArray/all).

Why it exists: bare PHP arrays allow any shape, so CRUD payloads passed between actions get no object syntax, no missing-key errors, and no element typing. This gives $c->key / $c['key'] / $c->get('key'), throwing reads, contains()/missing() guards, count()/foreach/JSON dump, and @var array<array-key, TValue> for PHPStan/Psalm — while staying a plain in-memory array.

1. Three read styles agree (on a hit)

$c = DemoContainer::make(['name' => 'Ada', 'role' => 'admin']);
$c->get('name'); // "Ada"
$c['name'];      // "Ada"
$c->name;        // "Ada" (via __get)

Writes differ in chainability, not value: set() returns static, __set/offsetSet return void.

2. All three throw on a miss

$c->get('nope'); // InvalidArgumentException: The nope key does not exist…
$c['nope'];      // same throw (offsetGet)
$c->nope;        // same throw (__get)

Guard first with contains(['a','b']) (bool) or missing(['a','b']) (first missing key, or false).

3. fill vs merge vs push

$c->fill(['a' => 1]);  // REPLACE whole array
$c->merge(['b' => 2]); // array_merge: string keys overwritten…
$c->push(99);          // $data[] = 99 (append)
$c[] = 99;             // same append (offsetSet with null offset)
after fill   {"a":1}
after merge  {"a":1,"b":2}
after push   {"a":1,"b":2,"0":99}

Int-key warning: merge is array_merge, so integer keys are renumbered and appended, never overwritten by key: [10,20] + merge([30]) → [10,20,30].

4. The null trap: isset lies

$n = DemoContainer::make(['maybe' => null]);
$n->contains(['maybe']); // true  (array_key_exists)
$n->missing(['maybe']);  // false (not missing)
$n->get('maybe');        // NULL, no throw
isset($n->maybe);        // false (__isset uses isset)
isset($n['maybe']);      // false (offsetExists uses isset)

Rule: never use isset to test presence. Reads and contains()/missing() use array_key_exists (null counts as present); isset paths use isset() (null counts as absent).

5. Count, iterate, dump

count($d);          // 2 (Countable)
foreach ($d as $k => $v) { /* … */ } // getIterator()
(string) $d;        // '{"x":1,"y":2}' (__toString = json_encode ?: '{}')
$d->toArray();      // ['x' => 1, 'y' => 2]
$d->all();          // identical alias

6. @template TValue is analysis-only

/** @template TValue @var array<array-key, TValue> $data */
DemoContainer::make(['s' => 'str', 'i' => 42, 'a' => [1]]); // runs fine

Runtime enforces only array. Mixed value types pass; element discipline comes from PHPStan/Psalm, not PHP.

Gotchas checklist

  • Missing reads throw — get(), [], -> all raise InvalidArgumentException.
  • fill replaces; merge is array_merge (int keys renumber); push/$c[] appends.
  • contains/missing/get see null as present; isset($c->k)/isset($c[k]) do not.
  • toArray() and all() are the same; __unset/offsetUnset silently ignore missing keys.
